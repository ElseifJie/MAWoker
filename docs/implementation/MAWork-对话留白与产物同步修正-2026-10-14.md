# 对话留白与产物同步修正

起点 main `09c87d3`，处理用户本轮四项反馈。

- 留白未生效的原因是页面 padding 使用了未定义的 `--ui-space-5`，导致整条声明失效。改为有效的 rem/百分比/clamp 值，增加标题上方、对话上下、消息之间与输入框内外留白，保留窄屏布局。
- 移除标题下“任务信息”及版本详情，隐藏“确认中”徽标；保留停止/删除保护和发送结果未知时的必要操作提示。
- 右侧栏默认关闭，移除独立打开入口；点击对话文件或明确文件链接后打开，关闭会清除选择，再点同一文件可重新打开。
- 真实 Ark Files 空清单返回 HTTP 200、application/json、4 字节 JSON `null`。原解析只接受列表页对象，误判协议错误并记录 ARTIFACT_SYNC_FAILED。现仅在 Files 清单接口兼容该空响应，同时保留页对象及 data-only 空页、分页与会话范围校验；不合法对象仍报错，其他接口解析方式保持原有行为。

验证：五项初始回归与一项精确真实 null 回归先失败后通过。实际任务的只读会话/文件查询已确认 idle 与空成果清单；新增 HTTP parser → 纯文字回合交付测试，确保不会误报同步失败。一次范围审查无发现。

最终受影响范围检查：40 个测试文件，541 项通过；两项下载流测试因沙箱监听端口 EPERM，获准在随机本地端口定向补跑后均通过，合计 543 项。工作区构建（含类型检查）、修改文件 Lint、格式及 diff 检查通过。最终格式整理保持全部非空白 TypeScript token 不变，复用测试/构建证据，不重复全量。未启动开发服务、未截图或浏览器视觉验证，用户服务保持原状。

已对截图对应且已确认无声明成果的旧回合，使用现有 owner/session 校验的 requestSyncRetry 安排一次正常重试；未直接强制改结果状态，也未重发用户对话。实际读回确认 artifact_state 为 synced、error_code 为 null；后台正常继续观察迟到文件。用户已有 material-picker 测试格式改动与 diagrams 未纳入提交。
