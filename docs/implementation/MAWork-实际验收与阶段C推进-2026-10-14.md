## UI 反馈落地范围

- 侧栏：标题单行省略，压缩左右占位；置顶仍可由菜单操作，完整标题在菜单可读。保持菜单键盘/触屏及原管理接口。
- 对话：移除页面/正文双层固定宽度造成的边缘留白，使用容器全宽与有上下限的内边距；正文约 15px/rem、适宜行高，保留表格/代码局部滚动与可靠状态。
- 新任务：助手名称显示一次，选择控件与提交动作同层；无效描述去除，记忆关闭说明、未知结果及错误保留。
- 搜索：弹层以工作区内容区域为中心，上方留适宜空间；窄屏和短窗口保持输入/结果可达，保留键盘/焦点行为。
- 助手配置：记录名称、描述与元数据回归同级控件字号，省略无描述占位和冗余说明。
- 记忆目录：按真实层级小幅缩进，文件名单行省略；保留完整名称/路径和展开/选中状态，CAS、维护锁及编辑不变。
